Local Git Quick Reference

A small cheat-sheet for initializing, committing, branching, and pushing.

  1. Go to the folder you want the repo in (use your terminal): 
    cd path/to/your/folder
  2. Initialize a repo: 
    git init
  3. To commit a change:
    1. Stage files: 
      git add .
      or 
      git add file.txt
    2. Create a commit: 
      git commit -m "Message text description"
  4. View commits: 
    git log
  5. Checkout commit or branch: 
    git checkout <commit-id-or-branch-name>

    To create and switch to a new branch:

    git checkout -b branch-name
  6. Connect to GitHub (add remote):

    If you use SSH keys:

    git remote add origin git@github.com:username/repo.git

    If you don't use SSH keys, follow the link below to set them up in a new tab:

    Set up SSH keys (opens new tab)

  7. Configure Git user & check config:

    Set your name and email for commits (local repo):

    git config user.name "CarelessCurve"
git config user.email "you@example.com"

    Set globally (applies to all repos on this machine):

    git config --global user.name "CarelessCurve"
git config --global user.email "you@example.com"

    Check configured values:

    git config user.name
git config user.email
git config --list

    Edit config file in your editor:

    git config --edit
git config --global --edit

    On Windows your global config typically lives at %USERPROFILE%\.gitconfig.

  8. Push to GitHub: 
    git push -u origin master
git push -u origin new-branch
  9. Create and merge pull requests:

    On GitHub open a Pull Request from your branch; repo owner can merge and resolve conflicts there.

  10. Pull changes from remote: 
    git pull origin master

Quick tips: replace master with your repo's default branch if different (e.g., main).
